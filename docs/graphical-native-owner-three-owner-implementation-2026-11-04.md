# Installed-only graphical IPC handoff — 2026-11-04

This source candidate replaces the unavailable graphical stage sender stub with a **fixed-path, authenticated, root-selected** Unix `AF_UNIX SOCK_SEQPACKET` IPC client. Missing root-published pin, missing original signed approval, stale boot identity or socket causes immediate **denial before any Host/SSM call**.

Root-control draft PR #33 has a separately persisted file claim/checkpoint, operator-signed original authorization verified in owner admission, one fixed installed script selected by operation ID, root-only private short-lived AWS session credential via systemd and irreversible never-retry. Host-install draft PR #27 defines disabled socket-activated units, protected mounts and gateway IAM policy, **without enabling anything**.

The gateway client reads a fixed protected root-published public pin and original signed operation from `/etc/zog/graphical-owner` (root-owned no-follow 0644, and protected ancestors) and verifies the current boot ID. It selects PR #30 exact original request from the gateway's frozen binding, rejecting any root-published approval for a different Host/installation/STATE/op/source/target/task/pin. Over the socket it verifies kernel `SO_PEERCRED` root identity and stable socket inode. After owner admission it verifies a **fresh nonce-bound Ed25519 signed owner observation**, exact original operation digest, scope and CommandId; a signed observation is never reusable send permission. It neither sends AWS SSM itself nor accepts caller-selected script, signer, socket path or alternate owner.

**Important remaining boundary:** native **preflight** is an SSM command too. The existing protected gateway `_selected_protected_owner_preflight` remains fail closed because a separately approved root original-preflight operation plus authenticated remote preflight receipt are not yet implemented. There is no direct fallback to `Host.command`. The deployment can therefore source-test the installed-only stage sender but is **not** runnable for graphical builds.

Native WORK acceptance must provide host-install's real installation and independently mounted checkpoint, external nonrollbackable highwater, source and RECORD attestation, current operator pin, guest boot/STATE and mount identity, protected peer PID/cgroup/invocation, native preflight operation and result, gateway STS/IMDS/SSM denied, owner-only temporary credentials, one actual SSM send, cancellation/revocation ordering, reboot/interruption/lost ACK and concrete remote command evidence. All production pins remain unchanged.
